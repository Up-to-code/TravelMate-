## Technology

Expo, React Native, React, TypeScript.

## Get started

```sh
git clone https://github.com/Up-to-code/TravelMate-.git
cd TravelMate-
```

Requires Node.js and npm.

```sh
npm ci
npm run dev
```

## Available commands

| Command | Purpose |
